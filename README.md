# Implementation sourcing review

Workspace for an implementation sourcing review at Northgate Research Labs.

The artifact under review is identified **only** by the source brief supplied
with the assignment (its exact title and its report identifier). Do not rely on
titles quoted elsewhere.

## Candidate scope

Only repositories owned by the account that hosts this review repository are in
scope.

## Procedure

1. Read the source brief and extract the artifact's exact title and report
   identifier.
2. Read `policy/implementation-selection-policy.md` and apply it.
3. Locate candidate repositories on the platform and verify each candidate's
   actual subject against the artifact identity.
4. Apply the traction metric and selection rule from the policy.
5. Write the completed decision record to `decisions/selection-record.json` on
   the default branch of this repository.
